# 配置指南：云端 AI 音乐服务与制作人大模型

适用版本：音序 Muse 0.3.0（仅桌面版；网页版没有这些功能）。更新日期：2026-10-09。

**先读这三句：**

- 不配置任何东西也能用——「本地作曲」和「离线规则」制作人完全离线、免费。本指南讲的两样东西都是可选的。
- 应用是按各家官方文档适配的，并且用本机模拟的服务跑通了完整流程；但**没有用任何真实付费账号验证过**。真实调用过的只有本机的 Ollama。你的第一次真实生成就是第一次真实验证：请从最短、最便宜的开始，并到服务商控制台核对记录。
- 密钥只在「设置」里填写，保存在本机并由 Windows 加密，界面读不回来。不需要设置环境变量，也不要把完整密钥发进聊天或截图。

两样东西各管什么：

| | 在哪里配置 | 做什么 | 费用 |
| --- | --- | --- | --- |
| **AI 音乐服务** | 设置 → AI 音乐服务，然后在「生成引擎」里选它 | 由服务商的模型生成整首音乐（一条混合音轨，没有分轨） | 每次生成一次付费请求，按服务商的价格 |
| **制作人大模型** | 设置 → 制作人大模型，然后在「制作人」里选它 | 理解你的话、安排编曲；音乐仍然可以由本地引擎免费合成 | 每发一句话一次模型请求，按服务商的 token 价格；本机 Ollama 不花钱 |

两者互不依赖：可以只用大模型 + 本地作曲，也可以只用离线规则 + 云端音乐。

## 第一部分：云端 AI 音乐服务

在「设置 → AI 音乐服务」里点开一家服务，填写后保存。**保存成功只代表已保存，不代表账号已开通**——保存时应用不发任何请求，第一次生成才会验证权限。

| 服务 | 要填什么 | 时长 | 开通要求 |
| --- | --- | --- | --- |
| 腾讯云 TokenHub | TokenHub API Key、音乐模型 | 15–120 秒都可以选，但只是写进描述的目标，实际长度由模型决定 | 开通 TokenHub，并为所选音乐模型开通后付费 |
| 火山引擎 AI 音乐 | Access Key ID、Secret Access Key、计费方式 | **30–120 秒**（选了火山之后时长里的 15 秒不可选；别处定下的 15 秒会在付费确认之前先问你要不要改为 30 秒）；有真正的时长参数 | 开通「生成纯音乐」，计费方式与控制台一致 |
| 阿里云百炼 Fun-Music | 北京地域 API Key、Workspace ID、音乐模型 | 只是写进描述的目标 | 北京地域、模型邀测通过、空间与 Key 对应 |
| ElevenLabs Music | API Key、音乐模型 | 作为参数传给服务 | 账户有 Music API 权限和额度；海外服务 |

从配置步骤看，建议先试**腾讯云 TokenHub**：只需要一项 API Key。已有火山 AI 音乐权限时也可以直接用火山；阿里云 Fun-Music 需要先通过邀测。下面的官方链接核对于 2026-10-08，开通条件和价格以各平台当时的页面为准。

### 1. 腾讯云 TokenHub

1. 登录腾讯云并开通 TokenHub，在 [TokenHub 密钥管理](https://console.cloud.tencent.com/tokenhub/apikey)创建 API Key。
2. 打开[在线推理 → 语音模型](https://console.cloud.tencent.com/tokenhub/inference?serviceType=SPEECH)，为 MiniMax Music v3.0 或 v2.6 开通后付费，并确认账户有可用额度。
3. 在应用的设置里选择腾讯云 TokenHub，填入这个 API Key，选择已开通的模型（默认 `minimax-music-v3.0`，另有 `minimax-music-v2.6`），保存。
4. 回到「创作」，把「生成引擎」切到腾讯云，写一段描述，生成。

要填的是 **TokenHub API Key**：不能用腾讯云的 SecretId / SecretKey，也不能用 MiniMax 官网的 Key。应用请求的是纯音乐模式。接口没有独立的时长参数，所选时长会作为一句「目标时长约 N 秒」写进描述；以生成后播放器显示的实际时长为准，选短的目标不等于一定按短片段生成或计费。[腾讯云官方音乐生成文档](https://cloud.tencent.cn/document/product/1823/135323)

### 2. 火山引擎 AI 音乐

1. 登录 [AI 音乐控制台](https://console.volcengine.com/ai-music/product)，开通「生成纯音乐」，按页面提示完成认证、权限和计费配置。
2. 在[访问密钥管理](https://console.volcengine.com/iam/keymanage/)创建或取得有该服务权限的 AK / SK（可以用已授权的子账号）。这里用的不是方舟聊天模型的 API Key。[官方快速接入指南](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/APIQuickAccessGuide?lang=zh)
3. 在应用的设置里填 Access Key ID 和 Secret Access Key，并选择与控制台相同的计费方式：买了套餐选预付费，开通按量计费选后付费（默认）。应用不会替你切换计费方式。[官方计费说明](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/Productbilling?lang=zh)
4. 选择火山引擎生成，时长选 **30 秒或更长**。

纯音乐接口是 v5.0，支持 30–120 秒，描述必须是中文（应用自己写的描述就是中文）。应用提交任务后每 2 秒查询一次，最长等 5 分钟，完成后从火山的官方 CDN 下载。等待中途停下来（连续 5 次查询失败、超过 5 分钟、你点了取消）时，已经提交的任务不会被丢掉：界面顶部会出现一条横幅，点「重新下载」就接着查询并取回这首音乐，不会再次提交、不会再次计费（见下文「应用为你做的计费保护」）。电脑时间不准会导致签名失败。较早的接入指南提到企业认证，当前的计费资料又有个人账号的说明，能否开通以你的控制台为准。[当前纯音乐 API](https://docs.volcengine.com/docs/Audiovideounderstandingandprocessing/Generatepuremusic?lang=zh)

### 3. 阿里云百炼 Fun-Music

1. 进入百炼控制台，切到**华北 2（北京）**，在模型广场申请 Fun-Music 邀测。普通的百炼聊天模型能用，不代表音乐模型已授权。[Fun-Music 官方使用指南](https://help.aliyun.com/zh/model-studio/fun-music)
2. 在该地域创建 API Key，并取得对应业务空间的 Workspace ID。Key、空间和地域必须对应。[获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)、[业务空间与接入域名说明](https://help.aliyun.com/zh/model-studio/regions)
3. 在应用的设置里填 API Key 和 Workspace ID。Workspace ID 填空间标识本身（只有字母、数字和连字符），不要填整个网址或空间的显示名称。选择已获批的模型（默认 `fun-music-preview`，另有 `fun-music-v1`），保存。
4. 把「生成引擎」切到阿里云，先提交一段简短的描述。

接口没有精确的时长控制，应用通过描述表达目标时长，并保留实际返回的音频。结果是一个下载链接，应用只从阿里云 OSS 的存储桶域名下载。[Fun-Music API 参数](https://help.aliyun.com/zh/model-studio/fun-music-api)

### 4. ElevenLabs Music

1. 在 ElevenLabs 创建 API Key（设置里这家服务下方的「服务商控制台」链接会打开它的密钥页），确认账户有 Music API 权限和可用额度。
2. 在应用的设置里填 API Key，选择模型（默认 `music_v1`，另有 `music_v2`、`music_v2_5`），保存。
3. 把「生成引擎」切到 ElevenLabs，生成。

应用把所选时长作为参数传给服务，并要求纯音乐；返回的是 MP3。这是海外服务，网络不通时需要系统代理——应用的主进程会使用 Windows 的系统代理设置（这一点没有在真实的代理环境里验证过）。

### 发给音乐服务的是什么

应用不会把你输入的原话原样发出去，而是把当前的设置写成一段中文描述：风格、速度、调、主奏乐器、情绪能量、旋律丰富度、空间混响、结构，以及你描述里仍然成立的部分，并且永远以「纯音乐，无人声，无歌词」结尾（最多 1800 字）。选了大模型做制作人时，这段描述由大模型来写，应用同样会补上纯音乐的要求。这段描述会随作品一起保存（工程数据里的 `cloud.prompt`），界面上目前不单独显示它。一起发出的只有目标时长、模型名和你的密钥。

这些是音乐方向，不是模型必须精确遵守的约束：速度、调性、音色、循环和时长都要听实际结果判断。云端返回的是已经混好的音乐，应用不会把它伪装成四条可调的分轨。

### 三段可以直接试的描述

- **青春日常**：阳光下的校园午后，青春欢快，轻盈钢琴、温暖贝斯和柔和鼓点，约 112 BPM，适合日常 Vlog。
- **午后专注**：安静的咖啡馆，温暖木吉他与稀疏钢琴，约 82 BPM，轻柔鼓点，旋律克制，适合阅读。
- **温柔叙事**：夜晚城市里的温柔电影配乐，钢琴主旋律、缓慢铺开的合成器和低音，约 88 BPM，略带忧郁但有希望，结尾自然收束。

先试一段，确认连通和效果，再试别的。

### 第一次真实生成的顺序

1. 先用「本地作曲」生成 15 秒，确认扬声器、播放和 WAV 导出正常。
2. 在设置里保存一家服务的凭据。
3. 腾讯或阿里选 15 或 30 秒；火山选 30 秒。点一次生成，在弹出的付费确认里点继续，等待完成。
4. 成功后确认：听得到声音、没有意外的人声、显示的是实际时长、作品出现在「我的作品」、导出的原始音频能播放。再到服务商控制台核对只有一次调用。
5. 要反馈问题时，记下服务名称、模型、发生时间、应用显示的错误文字和其中的编号（任务编号 / 请求编号 / 追踪编号）；不要附完整密钥。

## 第二部分：制作人大模型

制作人负责把「雨天咖啡馆里的慵懒钢琴」这样的话变成一份制作方案（风格、速度、调、乐器、编排）。内置的**离线规则**不需要任何配置。接入大模型后，自由的、绕弯的、带上下文的说法会理解得更好，它还能给出和弦进行、段落安排这类更细的编排。

在「设置 → 制作人大模型」里选一个服务，填写后保存；保存后「制作人」会自动切到大模型，随时可以切回「离线规则」。**每次保存都要重新填密钥**（这样已保存的密钥不会被悄悄指到另一个地址），本机 Ollama 除外。

### Claude（Anthropic）

- **密钥**：在 [Anthropic Console](https://console.anthropic.com/settings/keys) 创建的 API Key（以 `sk-ant-` 开头）。
- **模型**：从列表里选——`claude-opus-5-5`（默认）、`claude-sonnet-5-5`、`claude-haiku-5-5`。应用只接受这三个。
- 应用通过 Anthropic 的官方 SDK 调用，请求只发往 `https://api.anthropic.com`。你电脑上的 `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_CUSTOM_HEADERS` 之类的环境变量不会影响它——用的永远是你在设置里保存的那把密钥。
- 需要代理才能访问时，打开 Windows 的系统代理；应用的主进程会使用它（这一点没有在真实的代理环境里验证过）。

### OpenAI 兼容的服务

内置预设（地址已经填好，只需要密钥和模型名）：

| 预设 | 接口地址 |
| --- | --- |
| DeepSeek | `https://api.deepseek.com` |
| 通义千问（阿里云百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 豆包·火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` |
| 腾讯混元 | `https://api.hunyuan.cloud.tencent.com/v1` |
| OpenAI | `https://api.openai.com/v1` |
| 自定义 OpenAI 兼容接口 | 自己填 |

- **密钥**：该服务控制台里创建的 API Key。设置里有「获取 API Key」的链接（腾讯混元和自定义没有）。
- **模型名**：自己填，以服务商控制台的模型列表为准——各家经常改名，所以应用不内置这些名字。豆包填的是火山方舟控制台里的推理接入点 ID 或模型 ID。输入框里「形如 …」的占位文字只是格式示意，不是推荐，也不会被发送。
- **自定义地址的规则**：必须是 `https://` 开头的公网域名（通常以 `/v1` 结尾）；不能是 `http://`、本机、内网地址或单个主机名；不能带账号、查询参数；端口只能是 443 或 1024 以上，并且不能是浏览器内核拒绝连接的受限端口。应用会在地址后面加上 `/chat/completions`。本机模型请改选「本机 Ollama」。
- 这些预设的地址和密钥页链接是按各家文档填写的，**没有用真实账号逐个验证过**。

### 本机 Ollama

1. 在这台电脑上安装并启动 [Ollama](https://ollama.com/download)，下载一个模型（`ollama pull <模型名>`）。
2. 在设置里选「本机 Ollama」，模型一栏填 `ollama list` 里显示的名字，保存。地址默认是 `http://127.0.0.1:11434/v1`，只能是本机地址；不需要密钥。
3. 保存后应用会在后台让 Ollama 把模型载入内存（发一次只要 1 个 token 的请求），这样第一条消息不用等太久。

请求只发往这台电脑，不经过网络，也不花钱。需要注意：

- **慢**。在开发用的电脑上，一个 9B 的量化模型冷启动后的第一条回复用了约 2 分钟，之后每条 30–60 秒。Ollama 默认 5 分钟不用就卸载模型，隔久了再发又会遇到冷启动。
- **提示词不短**。系统提示词约 8900 个字符，Ollama 的上下文窗口需要 8k 以上（这要在 Ollama 一侧设置）。
- **小模型的判断有限**。实测的 9B 模型即使返回了合法的方案，也常常写出放不进时长的段落计划、在新作品里乱动分轨音量。应用会把这些明显不合适的部分丢掉或交还给作曲引擎，所以用小模型时得到的更接近「风格、速度、乐器选得对」，而不是精细的编排。想要更好的理解，用更大的模型或托管服务。

### 发给大模型的是什么

每发一句话，应用发出一次请求，内容是：

- 一段固定的系统提示词（约 8900 个字符：告诉模型它是音序的制作人、可选的风格和乐器、输出格式）；
- 最近最多 12 轮对话，每轮最多 600 字；
- 当前的音乐设置（风格、主奏乐器、调、速度、时长、三个滑块、结构、四条分轨音量；修改时还有当前的编排）；
- 你这句话（最多 1500 字），以及你在界面上固定的风格 / 时长 / 结构。

**不发送**：任何音频、你的作品库、作品标题、音乐服务的密钥。模型返回的方案在应用里会被校验两遍，超出范围的数值被夹回去，不认识的内容被丢弃。

**对话里显示的回复不是模型写的**：「好的：速度 84 → 72 BPM，主奏乐器换成柔和钢琴…」这一句由应用比较修改前后的设置写出，所以它说的就是实际发生的改动；模型自己的话作为「模型说明：…」附在下面，如果它提到了并没有发生的改动，这句说明就不显示。你明说的要求（比如「不要鼓」）优先于模型的选择。

### 费用

- 托管服务按 token 计费，价格以服务商为准。每句话的输入大约是上面那段固定提示词加上对话和设置；输出是一份几百到一两千字的 JSON 方案（上限：Claude 16000 token，OpenAI 兼容接口 4096 token）。
- **哪些操作会调用大模型**：只有在输入框里发送一句话（新作品或修改）。输入时的「理解预览」、「应用调整」、「换一版旋律」、点风格卡片都只用离线规则，不调用大模型。
- 应用不会为托管服务做预热请求。失败时最多自动再问一次（遇到限流或服务端错误）；Claude 的 SDK 也只重试一次。
- 大模型和云端音乐一起用时，一句话 = 一次模型请求 + 一次音乐生成请求，两边各自计费。

### 时间限制与回退

- **托管服务最多等 90 秒，本机模型最多等 240 秒**，从发出请求算起。等待时可以点「取消」。
- 超时、网络不通、密钥无效、模型拒答、返回的不是合法方案——任何失败，应用都会**改用离线规则**完成这次请求，并在对话里用一句话说明原因，例如「大模型超过 90 秒没有回应，已改用离线规则」。
- **例外**：如果生成引擎是付费的云端音乐服务，应用不会拿离线规则的方案直接去花钱，而是停下来问你：取消、重试大模型，还是用离线规则继续。

## 应用为你做的计费保护

- **发送前确认**：选了云端引擎后，发送、应用调整、重新生成一版都会先弹出付费确认，写明是哪一家服务。点取消或按 Esc 什么都不发。确认框出现后的半秒内不接受点击、回车和空格，按住不放的键也不算——连点两下或按住回车不会把它顺手确认掉。可以勾选「本次会话不再提示」（按服务记，重启后恢复）。建议按钮（如「慢一点」）在云端引擎下不会一点就发。
- **时长不合适先问**：服务不接受所选的时长时（例如给火山定了 15 秒），在付费确认**之前**就会问你「改为 30 秒」还是取消，不会先让你确认付费再拒绝。
- **从不自动重试一次生成**：超时、断网、服务端错误之后，应用只告诉你发生了什么，由你决定是否再试。
- **计费请求不会被网络层重发**：每家服务的那一个计费请求走一条专用的、每次都是全新连接的通道。连接中途断开时，应用报告「请求结果未确认」，请先到服务商控制台看记录。请求根本没有发出去的情况（比如还在准备连接时你就取消了）会明确写「没有发出」「不会计费」。
- **先保存，再解码**：音频一到就写进「我的作品」。解码失败的作品仍然在库里，可以导出原始音频。
- **保存失败不丢结果**：作品留在当前窗口，顶部出现横幅（重试保存 / 导出原始音频），3 秒后自动重试一次；离开这首作品前会先问你。
- **已经付费但没取回的结果不会被悄悄丢掉**（火山、阿里）：文件下载会自动重试几次；仍然失败，或者火山的任务提交了但没等到结果时，每个页面顶部都会出现一条**关不掉**的横幅。「重新下载」只是再取一次（火山的任务会接着查询），不会提交新的生成请求、不会再次计费；「放弃这次结果」要再确认一次。在取回或放弃之前，应用不会悄悄开始新的付费生成：再点生成、打开别的作品、新建创作都会先问你（取消 / 重新下载 / 放弃它继续）。重新加载界面后横幅会回来；但这份结果只留在应用本次运行的内存里，**退出应用后就取不回了**——所以关闭时一定会先问。
- **关闭前询问**：云端生成进行中、有付费结果还没保存或没取回时，关闭窗口或退出应用会先确认。没取回的结果由应用后台自己记着，不管界面上显示什么都会问。
- **取消如实说明**：取消只是停止等待，已经提交的请求服务端仍可能完成并计费。
- **大模型失败不会连带花钱**（见上一节的例外）。
- **不支持的参数不会发出去**：界面漏掉的情况，后台也会在发送前拒绝。
- **凭据缺失或损坏时不发请求**，并直接带你去设置。

这些保护都有自动化测试，但对象是模拟的服务；真实账单请以服务商控制台为准。

## 按现象排查

**生成引擎里选不了某家服务**

- 显示「需先在设置中配置」：还没保存这家的凭据。
- 显示「凭据需重新保存」（设置里是「凭据无法读取 · 请重新保存」）：保存的凭据解不开（换了 Windows 账户、恢复过系统）。在设置里重新填写保存即可。
- 显示「桌面版可用」：你在用网页版。

**保存凭据时出错**

- 「API Key 格式不正确」「…格式不正确，请填写完整凭据」：密钥要求是 10–4096 个不含空格的字符，检查是否多复制了空格或换行、是否只复制了一部分。
- 「Workspace ID 格式不正确」：填的是空间标识，不是网址或显示名称。
- 「系统密钥保护不可用，密钥未保存」：Windows 的加密服务暂时不可用，重新登录 Windows 后再试。
- 「无法读取服务凭据：凭据文件已损坏。请在设置中重新填写并保存密钥。」：`%APPDATA%\Muse BGM\music-credentials.json` 坏了（比如写到一半断电）。照它说的在设置里重新保存就行：应用会先把坏文件原样另存为同一目录下的 `music-credentials.damaged-<时间>.bak`，再从空白开始，并弹出一次提示告诉你副本的名字；之前保存的各家密钥都需要重新填写。
- 「无法读取服务凭据，请保留原数据目录并检查文件权限」：文件从磁盘上读不出来（多半是权限问题），或者它是更新版本的音序写的。这两种情况应用不会动它，保存也会被拒绝；请检查文件权限，或升级应用。

**生成失败，提示密钥或权限问题**

- 「API Key 无效或已过期」/「TokenHub API Key 无效或已过期」/「百炼 API Key 无效，请确认使用的是北京地域的密钥」：密钥类型或地域不对是最常见的原因——腾讯要 TokenHub 的 Key，阿里要北京地域的 Key。
- 「没有音乐模型访问权限」/「请先在 TokenHub 控制台开通对应音乐模型的后付费权限」/「当前账号没有 Fun-Music 模型的使用权限」：模型没开通、邀测没通过，或 Key 和业务空间不对应。
- 「火山引擎鉴权失败，请检查 AK/SK、子账号权限及纯音乐服务开通状态」：AK / SK 不对，或子账号没有这项服务的权限。
- 「火山引擎签名时间无效，请同步电脑时间后重试」：校准系统时间。
- 「账户额度不足」/「已欠费」：充值或检查后付费状态。
- 「请求过多或额度不足」/「触发限流」：稍等再试；应用不会自动重试。
- 「未通过内容审核」/「内容或版权校验未通过」：换一种描述，不要写具体的歌名、歌手。

**生成失败，提示网络或超时**

- 「无法连接音乐服务，请检查网络。请求结果未确认…」：请求可能已经到达服务，也可能没有。**先到服务商控制台看有没有这次调用**，再决定是否重试。
- 「没有发出请求，不会计费…」/「…这次请求还没有发出，不会计费。」：请求没有离开这台电脑，可以放心重试。
- 「AI 生成等待超过 5 分钟，已停止等待」：服务端任务可能还在跑。消息里的任务编号可以用来在控制台查找；火山的任务还会留在顶部的横幅上，点「重新下载」继续查询。
- 火山「任务状态连续 5 次查询失败，已停止等待」：网络不稳。任务已经提交，可能仍在生成并计费——**不要重新生成**，等网络恢复后点横幅上的「重新下载」，应用会接着查询并取回它（不再提交、不再计费）。消息里的任务编号也可以拿到控制台去查。
- 「还有一首已经付费的音乐没有取回，这次没有发出新的生成请求…」：上一次的结果还在等你。先点横幅上的「重新下载」；确实不要它了，就点「放弃这次结果」再生成。
- 海外服务连不上：打开 Windows 系统代理后重试。

**音乐生成了，但出了别的问题**

- 「音乐已生成，但下载失败…」：点顶部横幅上的「重新下载」。横幅关不掉，换页面、重新加载界面都还在；只有退出应用，或者你自己确认「放弃这次结果」之后，才只能按消息里的编号到服务商控制台去找这首音乐。
- 「《…》由 … 付费生成，在取消等待后才到达，还没有保存到「我的作品」…」的横幅：你取消等待之后结果还是到了，但保存没有成功。先点「导出原始音频」，再点「重试保存」。
- 「服务返回了非官方音频下载地址，已停止下载」：服务返回的下载地址不在应用认可的官方域名里。这首音乐已经计费；请按消息里的请求编号到控制台找回，并把这个情况反馈给开发者。
- 「这段音频无法解码试听」：音频已经保存，在「导出」里可以保存原始文件，用别的播放器打开。
- 出现「…还没有保存到「我的作品」，现在只存在于当前窗口」的横幅：本机存储出了问题。先点「导出原始音频」把文件拿到手，再点「重试保存」。
- 实际时长和所选的不一样：腾讯和阿里的时长只是写进描述的目标，属于正常情况。

**大模型不工作**

- 对话里出现「…，已改用离线规则」：前半句就是原因。常见的有：
  - 「API Key 无效或已过期」「Claude API Key 无效或已过期」——重新保存密钥。
  - 「当前密钥没有调用这个模型的权限」——模型没开通，或（Claude）受地区、组织设置限制。
  - 「大模型没有接受这次请求，请检查模型名称是否正确」——模型名填错了，以控制台为准。
  - 「大模型超过 90 秒没有回应」/「本机模型超过 240 秒没有回应」——换一个更快的模型，或稍后再试。
  - 「大模型没有按约定返回方案」/「回答被截断」——这个模型不擅长输出结构化内容，或开着深度思考把额度用完了；换一个模型，或关闭它的思考模式。
  - 「无法连接大模型服务」——检查网络、接口地址和系统代理。
- 保存设置时提示地址不正确：按上面「自定义地址的规则」检查。「接口地址解析到了本机或内网地址，已拒绝连接」说明这个域名指向内网，应用不会连接。
- 本机 Ollama：
  - 「无法连接本机的 Ollama，已改用离线规则」——Ollama 没有运行，或不在设置的端口上；先启动它，再核对设置里的地址和端口。
  - 「本机的这个地址或端口不可用，已改用离线规则」——那个端口上运行的不是 Ollama（被别的程序占着），或地址填错了。
  - 「设置里的端口是受限端口，已改用离线规则」——让 Ollama 改用别的端口（默认 11434）。
  - 「本机 Ollama 里没有这个模型，已改用离线规则」——模型名不对或还没下载，用 `ollama list` 核对名字。
- 托管服务提示「找不到这个模型或接口地址」：检查模型名称和接口地址（多数服务的地址以 `/v1` 结尾）。
- 设置里显示「设置无法读取，请重新保存」：保存的大模型设置解不开，重新填写保存。

**还是不行**

用「离线规则」+「本地作曲」确认应用本身正常；记下错误文字、时间、服务和模型，以及消息里的编号。真实账号下的表现目前没有任何测试数据，你的反馈就是第一手信息。
